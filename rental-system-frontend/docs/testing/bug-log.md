## Severity guidance
- `Critical`: The core workflow cannot be completed, the page is unusable, or the problem risks incorrect business outcome.
- `Major`: The workflow can continue, but an important step fails, gives clearly wrong results, or blocks a main admin task.
- `Minor`: The issue is real but limited. The workflow still works with a small workaround.
- `UX`: The issue is mainly clarity, wording, layout, or usability friction without breaking the main workflow.
